# Pipeline Quest

A gamified study app for data engineering. Open `index.html` in any browser; no build or server needed.

- 8 modules laid out as a pipeline DAG plus a final "Design Review" boss: Foundations, SQL, Storage & Formats, Data Modeling, Distributed Processing, Orchestration, Streaming, Quality & Governance.
- Each module has field notes to study and a quiz "job run" with XP, combo multipliers, 3 retries and 1–3 stars.
- Finishing a module unlocks the modules downstream of it. Ranks go from Intern to Principal DE, and there are 7 badges.
- After every run you get a review of the questions you missed, with explanations.
- Progress is saved in the browser's localStorage.
